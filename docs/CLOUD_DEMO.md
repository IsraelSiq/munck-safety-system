# 🌐 Cloud Dashboard Deployment

> Deploy automático de React dashboard em **Vercel**

## 🚀 Deploy em Vercel (1 minuto)

### Passos

1. Ir para: https://vercel.com/new
2. Conectar com GitHub
3. Selecionar: munck-safety-system
4. Clicar: Deploy
5. **✅ URL gerada automaticamente!**

## 🎥 Dashboard Features

### 📹 Câmeras em Looping
- 4 vídeos MP4 (30s cada) em looping
- Status online/offline com cores (verde/vermelho)
- Resolução 1920x1080 @ 30fps

### 🚨 Alarmes Visuais
- Fundo RED com animação pulsante
- Exibe: Pessoa #ID em zona_XX
- Auto-stop após 5 segundos

### 📊 Estatísticas Executivas
- Câmeras Online: X/4
- Intrusões: X
- Pessoas Rastreadas: X
- Tempo Online: Xh Xm

### 📝 Event Log (Real-time)
- Últimas 100 eventos
- Scroll automático
- Filtrados por tipo (INTRUSION, HEARTBEAT, etc)

### 🔗 API Status
- Dashboard API status
- Event Store status
- YOLO11 Model info
- ByteTrack Engine status
